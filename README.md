КТ3 Роутинг и навигация 

## Реализованный функционал

- **Маршрутизация**
- **Навигация без перезагрузки**
- **Динамический маршрут и Query-параметры**:
  - Чтение параметра пути `/products/:id` через типизированный `useParams`.
  - Сортировка и фильтрация каталога через `useSearchParams`.
- **Защищённый маршрут (`PrivateRoute`)**

  ## Запуск проекта
  npm run dev
